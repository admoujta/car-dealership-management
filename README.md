# Car Dealership Management System

A simple C project for managing a car dealership inventory using linked lists.

The program allows the user to manage cars in stock through a menu-based interface.

## Features

- Add a car to the stock
- Modify car information
- Delete a car from the stock
- Search for a car
- Display available cars

## Technologies

- C Programming Language
- Linked Lists
- Structures
- Pointers
